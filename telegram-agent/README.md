# סוכן דירות לטלגרם

סורק לוחות דירות כל חצי שעה, מסנן לפי הקריטריונים שלך, ושולח לך בטלגרם
רק מה שחדש ומתאים. בלי לפתוח אתרים, בלי לגלול, בלי לראות פעמיים את אותה מודעה.

מכוון מראש לחיפוש: **2 חדרים, עד 4,000 ₪, גינה, מרשה בעלי חיים** — בנטעים,
בית עובד, בית חנן, כפר הנגיד ופלמחים, וגם בראשון לציון (3,500–4,000) ובנס ציונה.

---

## מה הוא עושה

1. **סורק** את הומלס, יד2 ואופציונלית קבוצות פייסבוק
2. **מחלץ** מכל מודעה יישוב, רחוב, חדרים, מחיר, מ״ר, וסימנים לגינה/מרפסת/בעלי חיים
3. **מדרג** לפי התאמה — גינה ואישור לבעלי חיים מעלים ציון משמעותית
4. **זוכר** מה כבר נשלח, כך שכל מודעה מגיעה אלייך פעם אחת בלבד
5. **שולח** בטלגרם, הכי מתאימה קודם

מודעה עם גינה שמרשה בעלי חיים תגיע עם 🔥. בינונית עם ⭐. שאר המתאימות עם •.

## התקנה

```bash
cd telegram-agent
pip install -r requirements.txt
python -m playwright install chromium     # רק אם רוצים את יד2 או פייסבוק
```

### חיבור לטלגרם

1. בטלגרם, פתחי צ׳אט עם **@BotFather** ושלחי `/newbot`. בחרי שם, וקבלי טוקן.
2. שלחי הודעה כלשהי לבוט החדש שלך (זה הכרחי — בלי זה טלגרם לא ייתן את ה-chat_id).
3. הריצי:

```bash
export TELEGRAM_TOKEN="הטוקן שקיבלת"
python -m dira whoami
```

זה ידפיס את ה-chat_id שלך. הגדירי גם אותו:

```bash
export TELEGRAM_CHAT_ID="המספר שהודפס"
```

### בדיקה שהכול מחובר

```bash
cp config.example.yaml config.yaml
python -m dira check          # מוודא שהקונפיג תקין
```

לפני שנוגעים בסקרייפרים, כדאי לוודא שההתראות בכלל מגיעות. פתחי את
`config.yaml`, שני `demo: enabled: true`, והריצי `python -m dira scan`.
אמורות להגיע שתי הודעות. אחר כך החזירי ל-`false`.

## שימוש

```bash
python -m dira preview             # מה היה נשלח — בלי לשלוח וبלי לסמן כנקרא
python -m dira preview --rejected  # וגם מה נפסל, ולמה
python -m dira scan                # סריקה אחת + שליחה
python -m dira scan --dry-run      # סריקה בלי שליחה ובלי שמירת מצב
python -m dira bot                 # ריצה רציפה + פקודות בטלגרם
```

`preview` הוא הפקודה שכדאי להתחיל בה תמיד אחרי שינוי בקונפיג —
היא מראה בדיוק מה הסוכן חושב, בלי לבזבז מודעות.

### פקודות בטלגרם (במצב `bot`)

| פקודה | מה היא עושה |
|---|---|
| `/scan` | לסרוק עכשיו |
| `/status` | מה מוגדר ומתי נסרק לאחרונה |
| `/pause` | להשתיק התראות |
| `/resume` | להחזיר |
| `/help` | התפריט |

## הרצה אוטומטית

### GitHub Actions (מומלץ — חינם, בלי מחשב דלוק)

הוגדר כבר ב-`.github/workflows/dira-scan.yml`, רץ כל 30 דקות.
כדי להפעיל, הוסיפי שני secrets בריפו — **Settings → Secrets and variables → Actions**:

- `TELEGRAM_TOKEN`
- `TELEGRAM_CHAT_ID`

זהו. הסוכן ירוץ לבד, וישמור את רשימת המודעות שנשלחו בחזרה לריפו כדי
שלא תקבלי כפילויות.

**מגבלה אחת:** פייסבוק לא יכול לרוץ ב-Actions, כי הוא צריך את הסשן
המחובר שלך. הוא ירוץ רק על מחשב שלך.

### על המחשב שלך

```bash
python -m dira bot
```

## פייסבוק — קראי לפני שמפעילים

זה המקור היחיד שדורש את החשבון שלך, ולכן הוא **כבוי כברירת מחדל**.

**איך זה עובד:** את מתחברת פעם אחת בעצמך בחלון דפדפן שנפתח, הסשן נשמר
מקומית ב-`~/.dira/fb-profile`, והסוכן משתמש בו. **הסיסמה שלך לא עוברת
דרך הקוד ולא נשמרת בשום מקום.**

```bash
python -m dira login-facebook     # פעם אחת
```

ואז ב-`config.yaml`: `facebook: enabled: true`.

**שלוש אזהרות אמיתיות:**

1. **סריקה אוטומטית מנוגדת לתנאי השימוש של פייסבוק.** בקצב גבוה זה עלול
   להוביל להגבלה או לחסימה של החשבון. זו החלטה שלך — לכן זה כבוי כברירת מחדל.
2. **ברירות המחדל כאן איטיות בכוונה** — שלוש קבוצות, גלילה קצרה, 15 שניות
   בין קבוצות. אל תורידי אותן.
3. **פייסבוק משנה את המבנה שלו תכופות.** הסוכן נשען על תפקידי ARIA ולא על
   שמות class, וזה עמיד יותר — אבל אם ישבר, הסריקה תחזיר אפס מודעות
   ולא תקרוס. אם פייסבוק פתאום מחזיר 0 בזמן שאת רואה פוסטים — זה מה שקרה.

## כוונון

הכול ב-`config.yaml`.

**מגיעות יותר מדי התראות?** העלי את `min_score` ל-60 (רק מודעות עם
גינה או אישור לבעלי חיים יעברו), או הפעילי `require_outdoor: true`.

**מגיעות מעט מדי?** הורידי את `min_score` ל-0, הרחיבי `max_rooms`,
והוסיפי יישובים ל-`areas`.

**תקרת מחיר שונה לכל אזור** — זה מה ש-`areas` נותן. בראשל״צ יש רצפה של
3,500 כי מתחתיה זה כמעט תמיד חדר ולא דירה; במושבים אין רצפה.

**גינה ומרפסת לא מפסילות** בכוונה, כי מודעות רבות פשוט לא מציינות
אותן בטקסט — הן רק מעלות ציון. אם את מוכנה לפספס כאלה בשביל שקט,
`require_outdoor: true`.

## מבנה

```
dira/
  models.py       מודל המודעה + חילוץ מחיר/חדרים/מ״ר/גינה/בעלי חיים מטקסט
  config.py       טעינת YAML, כללי מחיר לפי אזור
  matching.py     ההחלטה מה מתאים ובאיזה ציון
  format.py       עיצוב הודעות טלגרם
  telegram.py     לקוח טלגרם עם ניסיונות חוזרים
  store.py        זיכרון מה כבר נשלח (JSON, כתיבה אטומית)
  agent.py        סריקה אחת מקצה לקצה
  sources/
    homeless.py   HTML רגיל — המקור הכי אמין
    yad2.py       דפדפן אמיתי, כי יד2 מוגן מפני בוטים
    facebook.py   דפדפן עם הסשן שלך
    demo.py       מודעות מומצאות, לבדיקת חיווט
```

**להוסיף מקור חדש:** כתבי `fetch(options) -> list[Listing]` בקובץ חדש
תחת `sources/`, והוסיפי שורה ל-`REGISTRY` ב-`sources/__init__.py`. זהו.

## מה לא נבדק, ולמה

הלוגיקה הפנימית — פרסינג, סינון, דירוג, דה־דופליקציה, עיצוב הודעות —
נבדקה ועובדת.

**מה שלא יכולתי לבדוק: החיבור החי לאתרים עצמם.** הסביבה שבה נכתב הקוד
חוסמת גישה יוצאת לכל אתרי הנדל"ן ולפייסבוק, ולכן הסקרייפרים מעולם לא
רצו מול שרת אמיתי. הפרסר של הומלס נבנה מול כותרות מודעה אמיתיות שנאספו
בחיפוש, ולכן הוא כנראה מדויק — אבל מבנה ה-HTML של הדף עצמו לא אומת.

**מה לעשות אם משהו מחזיר אפס:**

```bash
python -m dira preview --rejected
```

זה מראה כמה מודעות נאספו מכל מקור. אם מקור מחזיר 0 — הסלקטור שלו
צריך עדכון. שלחי לי את הפלט ואתקן.
